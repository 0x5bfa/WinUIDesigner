<h1 align="center">WinUI 3 Designer for Visual Studio</h1>
<p align="center">WinUI 3 designer integration for Visual Studio.</p>

> [!WARNING]
> This repository is an experimental project. It is not a production-ready and does not represent a released or Marketplace-published VSIX.

## Usage

[![Visual Studio Marketplace Version](https://vsmarketplacebadges.dev/version/0x5bfa.WinUI3Designer.svg)](https://marketplace.visualstudio.com/items?itemName=0x5bfa.WinUI3Designer)

Download and open a vsix file from Visual Studio Marketplace. WinUI 3 designer will be automatically available for WinUI 3 projects.
