# WinUI 3 XAML Designer

Experimental preview. Core design-time behavior and Visual Studio/Windows App SDK compatibility are still being validated.

## Known limitations

- Selection, move, resize, hit testing, and undo/redo are not yet reliable. During move or resize, the rendered element, selection adorners, and hit-test bounds can diverge or flicker.
- WinUI-aware Toolbox discovery and control creation are incomplete.
- Compatibility across Visual Studio and Windows App SDK versions is still being established.
- Complex application resources, VisualState, Storyboard, styles, templates, design-time metadata, and complete serialization are not fully supported.
